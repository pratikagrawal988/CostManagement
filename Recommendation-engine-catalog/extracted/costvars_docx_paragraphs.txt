AI Cost Variables  +  Tooling Framework
Infrastructure to Application  ·  7 Layers  ·  40+ Variables  ·  Open-Source & Commercial Tool Map
Every cost driver defined, its optimisation opportunity stated, the exact telemetry needed to detect it, and the recommended open-source or commercial tool to capture and act on it.
How to read this document:  Each cost variable table has 5 columns: (1) Cost Variable — name and layer. (2) Definition — what it is. (3) ⚡ Cost Driver / ✓ Optimisation Opportunity. (4) Telemetry Required — exact metric names and sources. (5) Recommended Tooling — open-source (OSS) and commercial tools that provide this signal or enable the optimisation. The Tooling Chapter at the end maps every tool across layers with build-vs-buy guidance.

GPU Idle Time
GPU provisioned and powered on but running no compute — training cluster idle between jobs.
⚡ Full hourly GPU rate billed even at 0% utilisation; idle clusters are the #1 GPU waste pattern
✓ Detect idle >10 min → scale-down or spot reclaim; separate reservation vs on-demand

GPU Utilisation Rate
% of GPU SM cycles executing real matrix operations — the core efficiency metric for any GPU workload.
⚡ Training at 30–50% SM utilisation wastes 50–70% of GPU cost per hour
✓ Tune batch size, enable tensor parallelism, Flash Attention; every +10% util = -10% cost
• dcgm_gpu_sm_utilization (%)

• NVIDIA Nsight Systems kernel trace

GPU Memory Utilisation

⚡ A100 80GB billed when model fits in L4 24GB; 3× unnecessary cost
✓ Quantise model (FP16→INT8/INT4); MIG slicing; right-size GPU tier per workload

GPU MIG Efficiency
Utilisation of each MIG slice vs cost of the full physical GPU it is carved from.
⚡ Small inference workload using full A100 when 1g.10gb MIG slice suffices; 6/7 wasted
✓ Profile concurrency + memory per service; right-size to appropriate MIG instance type

CPU–GPU Stall
CPU-bound data loading that starves the GPU — GPU waits idle while CPU prepares the next batch.
⚡ GPU idles while CPU dataloaders run; both GPU and CPU billed at full rate for wasted time
✓ Use NVIDIA DALI (GPU-native data pipeline), async prefetch, increase DataLoader workers

Spot Preemption Waste

• Checkpoint write duration + storage cost

Platform Tooling Principle:  The FinOps AI Platform is not a tooling replacement — it is a cost intelligence layer that ingests signals from every tool listed in the Tooling column above. Open-source tools (◆) form the data collection backbone. Commercial tools (●) accelerate where OSS cannot automate or scale. Our platform translates all these signals into dollar-denominated opportunities ranked by ROI and routed to the right team.
Legend:  ◆ = Open Source  ·  ● = Commercial / SaaS  ·  ⚡ = Cost driver (how money is wasted)  ·  ✓ = Optimisation opportunity (how to save)
