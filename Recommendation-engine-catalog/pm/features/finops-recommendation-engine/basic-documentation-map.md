# Basic Recommendation Engine - Documentation Map

Use these documents together:

1. `prd-basic.md` - control PRD and acceptance criteria.
2. `basic-requirements-critical-review.md` - critical gap review and revamped Basic-only scope.
3. `basic-recommendation-catalog.md` - usage guide for the 1,030-row global catalog.
4. `basic-recommendation-catalog-global.csv` - prioritized recommendation definitions with metrics, thresholds, benefits, and advisory mappings.
5. `basic-costvars-advisory-mapping.md` - CostVars advisory ID to configured recommendation row mapping.
6. `basic-recommendation-catalog-500.csv` - stable 500-row seed retained for comparison.
7. `basic-integration-framework-guide.md` - CSP, SaaS, Kubernetes, AI, and Product Catalog setup guide.
8. `basic-product-catalog-coverage.md` - extracted AWS/Azure/GCP catalog inventory and Product Catalog view requirements.
9. `basic-system-user-guide.md` - end-to-end guide for setup, selection, backtest, activation, findings review, actions, and reconciliation.

Advanced recommendations are explicitly out of scope for this package.
